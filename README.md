# OKTOBER Brewery website

A responsive public website built with React and Create React App.

## Run locally

1. Install Node.js (LTS) if it is not already installed.
2. In this folder, run `npm install` the first time.
3. Run `npm start` and open `http://localhost:3000`.
4. Run `npm run build` to create the optimized production site in `build/`.

## Deploy

The production build is a static site. It can be deployed to Netlify or Vercel by connecting the repository and using `npm run build` as the build command and `build` as the publish/output directory. Route fallback files are included for the client-side pages.

## Finish the real business details before publishing

- Confirm the public brand name and approved story copy.
- Replace the menu preview with the current menu, descriptions, prices and product photography.
- Add the exact venue address, map link, opening hours, reservation/contact details and social links.
- Review local requirements for alcohol-related website content and age notices before launch.
- Set the final website URL and update the search/social preview metadata in `public/index.html`.

The original project archive included sample menu content with mismatched descriptions and repeated prices. Those unverified details were not carried into this version.
